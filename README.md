## 📌 درباره نسخه جدید زرین بوت در لاراول ۱۳ (ZarinBot Laravel 13 Overview)

این نسخه از **زرین بوت (ZarinBot)** کاملاً بر پایه فریم‌ورک **لاراول ۱۳ (Laravel 13)** و **PHP 8.3/8.4** از پایه بازنویسی و کدنویسی گردیده است. تمامی ۳۳ ماژول اصلی شامل اتوماسیون اینستاگرام، ارسال ایمن پیام در واتساپ، استخراج شماره‌های گروه‌ها و کانال‌های واتساپ، ماینر بیزینس‌های محلی، تحلیل هوش مصنوعی Arena.ai، تسویه‌حساب دوگانه SaaS، کدهای تخفیف ترکیبی، متون حقوقی فتا، وبلاگ WYSIWYG، و موتور یکپارچه رفع فیلترینگ بدون نیاز به VPN با سرعت بارگذاری فوق‌العاده بالا و طراحی شیک و مدرن پیاده‌سازی شده‌اند.

## ✨ ویژگی‌های برجسته نسخه لاراول ۱۳

1. **طراحی فوق‌العاده شیک و مدرن (Ultra-Stylish Glassmorphism Design)**:
   * تم تاریک و جذاب با کامپوننت‌های شیشه‌ای، انیمیشن‌های روان و واکنش‌گرایی کامل در تمامی دستگاه‌ها (موبایل، تبلت، دسکتاپ).
2. **پانویس داینامیک HTML قابل ویرایش توسط سوپر ادمین**:
   * امکان ویرایش لایو متن پانویس از پنل مدیریت (پیش‌فرض: `© تمامی حقوق برای زرین بات محفوظ می باشد. | احسان نادری پناه - 09024561001`).
3. **سرعت بارگذاری فوق‌العاده بالا (High Performance & Ultra-Fast Loading)**:
   * کش هوشمند پیکربندی‌ها و مسیرها، بلید کامپایل‌شده لاراول ۱۳ و کوئری‌های بهینه‌سازی شده دیتابیس.
4. **موتور یکپارچه رفع فیلترینگ (Anti-Censorship Core Engine)**:
   * استعلام امن Cloudflare DoH (`https://1.1.1.1/dns-query`).
   * خردسازی پکت‌های TLS ClientHello جهت عبور بدون VPN از فیلترینگ اپراتورها در ایران.
5. **استخراج اعضای گروه‌های واتساپ با ردگیری صریح**:
   * ثبت نام و تلفن کاربر استخراج‌کننده (`extracted_by_full_name`, `extracted_by_phone_number`) و بانک متمرکز سوپر ادمین.
6. **معماری دوگانه اشتراک (Dual-SaaS Billing)**:
   * پلن‌ها و فاکتورهای مجزای ربات اینستاگرام از ربات واتساپ همراه با اعمال چند کد تخفیف همزمان.
7. **نصب‌کننده آنلاین ۳ مرحله‌ای هاست (WordPress-Style Web Installer)**:
   * راه‌اندازی آسان در `/install` همراه با ثبت لاگ فتا (`has_accepted_terms = true`) و قفل `installed.lock`.

## 🛠️ راهنمای راه‌اندازی و نصب پکیج لاراول ۱۳ روی هاست

### ۱. نصب پیش‌نیازها و دستورات Composer
```bash
# نصب پکیج‌های Composer
composer install --optimize-autoloader --no-dev

# ایجاد فایل .env و تولید کلید اپلیکیشن
cp .env.example .env
php artisan key:generate

# اجرای مایگریت دیتابیس و دیتابیس اولیه
php artisan migrate:fresh --seed
```

### ۲. نصب آنلاین ۳ مرحله‌ای در مرورگر
آدرس زیر را باز کنید:
```text
https://your-domain.com/install
```
مراحل ۳ گانه را طی کنید تا دیتابیس و حساب سوپر ادمین به صورت خودکار ایجاد گردند.

## 📂 ساختار پروژه‌های لاراول ۱۳ (Folder Structure)

```text
ZarinBot_Laravel/
├── app/
│   ├── Http/Controllers/                  # کنترلرهای API، آنلاین استالر، واتساپ و دمو
│   ├── Models/                           # مدل‌های Eloquent لاراول ۱۳
│   └── Services/                         # موتور آنتی‌فیلتر، واتساپ، تسویه‌حساب و لید ماینر
├── config/
│   └── zarinbot.php                      # تنظیمات اختصاصی زرین بوت
├── database/
│   ├── migrations/                       # مایگریشن‌های تمامی جداول دیتابیس
│   └── seeders/                          # سیدر اولیه پلن‌ها، متون حقوقی فتا و وبلاگ
├── resources/
│   └── views/                            # قالب‌های بلید با دیزاین بسیار شیک و مدرن
└── routes/
    ├── web.php                           # مسیرهای وب، دمو و پنل مدیریت
    └── api.php                           # ای‌پي‌آی‌های RESTful زرین بوت
```
